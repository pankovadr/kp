# Курсовой проект по программированию

## Вариант 8. Мониторинг реактора: температура охлаждающей жидкости

### 1. Постановка задачи

Разработать программу на языке C для мониторинга температуры охлаждающей жидкости химического реактора.

Программа предназначена для:

- получения показания датчика температуры X;
- проверки допустимого диапазона входных данных;
- преобразования температуры X в показатель Q(X);
- оперативного контроля состояния технологического процесса;
- подготовки программного каркаса для последующего статистического анализа.

На этапе КТ1 реализуются основные функции программы и проверка вычислений. Полноценный статистический анализ предусмотрен на следующем этапе.

### 2. Исходные данные

| Параметр | Значение |
|---|---|
| Измеряемая величина | Температура охлаждающей жидкости X |
| Единица измерения | °C |
| Допустимый диапазон X | 10–50 °C |
| Базовое значение Q | 50 |
| Допустимое отклонение Q | ±10 |

### 3. Преобразование показания

Показание датчика преобразуется по заданной кусочной функции:

$$
Q(X)=
\begin{cases}
6\sqrt{|X-20|}+5, & X<20,\\
2(X-26)+50, & 20\le X\le32,\\
0.25(X-32)^2+55, & X>32.
\end{cases}
$$

Допустимый диапазон входного значения:

$$
10\le X\le50
$$

Если введённое значение не является числом или выходит за допустимый диапазон, программа сообщает об ошибке и прекращает вычисления.

**Особенность функции:** при X = 20 наблюдается скачок значения Q. При приближении к 20 слева Q стремится к 5, а при X = 20 по второй ветви Q = 38.

Также скачок наблюдается при X = 32: по второй ветви Q = 62, а при приближении справа значение Q стремится к 55.

Эти особенности следуют из заданной индивидуальной формулы. Программа использует её без изменений.

### 4. Архитектура программы

Программа состоит из трёх файлов:

- `main.c` — главная функция, организация работы программы и вывод сообщений;
- `kp.h` — объявления функций и констант;
- `kp.c` — определения функций.

Основные функции программы:

- `read_x(double *x)` — считывает значение температуры и возвращает результат проверки ввода;
- `compute_q(double x)` — вычисляет показатель Q(X) по кусочной функции;
- `control(double q)` — определяет состояние технологического процесса;
- `statistics(void)` — заглушка статистического анализа для следующего этапа.

Обработка показания выполняется по цепочке:

`X → compute_q(X) → Q → CONTROL → STATE`

Взаимодействие с пользователем, проверка допустимого диапазона и вывод состояния организованы в функции `main()`.

### 6. Алгоритм работы программы

1. Вывести приветствие и назначение программы.
2. Получить значение температуры X.
3. Проверить корректность ввода.
4. Проверить условие 10 ≤ X ≤ 50.
5. Передать X в функцию `compute_q()`.
6. Рассчитать Q(X) по соответствующей ветви кусочной функции.
7. Передать Q в функцию `control()`.
8. Сравнить отклонение |Q − 50| с допустимым значением 10.
9. Определить состояние процесса:
   - НОРМА, если |Q − 50| ≤ 10;
   - ТРЕВОГА, если |Q − 50| > 10.
10. Вывести значение Q и состояние процесса.

Статистический анализ будет реализован на следующем этапе курсового проекта.

### 7. Ручные контрольные расчёты

#### Тест 1. Нижняя ветвь

При X = 16:

$$
Q(16)=6\sqrt{|16-20|}+5
$$

$$
Q(16)=6\sqrt{4}+5=6\cdot2+5=17
$$

Результат: **Q = 17.00**

Отклонение от базового значения:

$$
|17-50|=33>10
$$

Состояние: **ТРЕВОГА**.

#### Тест 2. Средняя ветвь

При X = 26:

$$
Q(26)=2(26-26)+50=50
$$

Результат: **Q = 50.00**

Отклонение:

$$
|50-50|=0\le10
$$

Состояние: **НОРМА**.

#### Тест 3. Верхняя ветвь

При X = 36:

$$
Q(36)=0.25(36-32)^2+55
$$

$$
Q(36)=0.25\cdot16+55=59
$$

Результат: **Q = 59.00**

Отклонение:

$$
|59-50|=9\le10
$$

Состояние: **НОРМА**.

### 8. Контрольный пример

Для значения X = 26 ожидается следующий результат:

```text
X = 26.00 °C
Q(X) = 50.00
Состояние: НОРМА
```

### 9. Проверка и ограничения

Входное значение X должно:

- быть числом;
- находиться в диапазоне от 10 до 50 °C.

При некорректном вводе программа выводит сообщение об ошибке и завершает работу.
