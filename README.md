# Курсовой проект
## Вариант 8: Мониторинг реактора: температура охлаждающей жидкости реактора.
## Постановка задачи
Разработать программу на языке C, которая выполняет следующие действия:
1. Получает значение температуры X (в °C).
2. Определяет, к какому диапазону относится значение X.
3. Вычисляет показатель Q по соответствующей кусочно-заданной формуле.
4. Выводит полученный результат на экран.
5. Выполняет проверку контрольного примера. 
## Исходные данные:
Диапазон входных значений X: от 10 до 50 °C.

Функция преобразования Q(X):
 Q(X) = 6 \cdot \sqrt{X - 20 + 1} + 5, при X < 20
 Q(X) = 2 \cdot (X - 26) + 50, при 20 \le X \le 32
 Q(X) = 0.25 \cdot (X - 32)^2 + 55, при X > 32 
## Контрольный пример:
При X = 26.0
Ожидаемый результат: Q = 50.00
