# Курсовой проект
## Вариант 8: Мониторинг реактора: температура охлаждающей жидкости реактора.
## Постановка задачи
Программа предназначена для мониторинга технологического процесса в химическом реакторе по параметру "Температура охлаждающей жидкости". Программа преобразует измеряемые значения в нормированный показатель Q, проводит оперативный контроль состояния процесса и статический анализ выборки. 
## Исходные данные:
Диапазон входных значений X: от 10 до 50 °C.
Функция преобразования Q(X):

$$
Q(X) = 
\begin{cases} 
6\sqrt{|X - 20|} + 5, & \text{при } X < 20 \\
2(X - 26) + 50, & \text{при } 20 \le X \le 32 \\
0.25(X - 32)^2 + 55, & \text{при } X > 32 
\end{cases}
$$

**Ограничение входных данных:**
Допустимый диапазон значений температуры X: **от 10 до 50 °C**. 
Если введенное значение выходит за эти пределы (X < 10 или X > 50), программа должна прерывать расчет и выводить сообщение об ошибке ввода (например: "Ошибка: температура выходит за допустимые пределы").
### Ручные тесты (проверка всех веток формулы)

*   **Тест 1 (Ветка X < 20):** Входное значение `X = 16`.
    *   Расчет: Q(16) = 6 * sqrt(|16 - 20|) + 5 = 6 * sqrt(4) + 5 = 6 * 2 + 5 = **17.00**
*   **Тест 2 (Ветка 20 <= X <= 32):** Входное значение `X = 26`.
    *   Расчет: Q(26) = 2 * (26 - 26) + 50 = 0 + 50 = **50.00**
*   **Тест 3 (Ветка X > 32):** Входное значение `X = 36`.
    *   Расчет: Q(36) = 0.25 * (36 - 32)^2 + 55 = 0.25 * 16 + 55 = 4 + 55 = **59.00**
## Контрольный пример:
При X = 26.0
Ожидаемый результат: Q = 50.00
