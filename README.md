# Курсовой проект
## Вариант 8: Мониторинг реактора: температура охлаждающей жидкости реактора.
## Постановка задачи
Программа предназначена для мониторинга технологического процесса в химическом реакторе по параметру "Температура охлаждающей жидкости". Программа преобразует измеряемые значения в нормированный показатель Q, проводит оперативный контроль состояния процесса и статический анализ выборки. 
## Исходные данные:
Диапазон входных значений X: от 10 до 50 °C.
Функция преобразования Q(X):
 Q(X) = 6*sqrt{X - 20 + 1} + 5, при X < 20
 Q(X) = 2*(X - 26) + 50, при 20 <= X <= 32
 Q(X) = 0.25*(X - 32)^2 + 55, при X > 32 
## Ручной пересчет (Примеры):
X = 30 -> Q_1 = 2(30-26)+50 = 58.00

X = 31 -> Q_2 = 2(31-26)+50 = 60.00

X = 32 -> Q_3 = 2(32-26)+50 = 62.00
## Контрольный пример:
При X = 26.0
Ожидаемый результат: Q = 50.00
